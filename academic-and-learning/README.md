## Reading the evidence

The original repositories retain their source history, assignment identifiers, supporting files and existing notices. The public collection contains reviewed snapshots, with partial projects identified in their guides. It adds no new general license. Course-provided tests, third-party images and other excluded material remain in the reference archives with their existing notices. Historical executables are not offered here as verified builds.

Some retained READMEs describe intended performance, memory behavior or compatibility. Treat those as historical claims unless a current source record provides a specific verification result. My current systems work remains in [Windows-System-Administration](https://github.com/davidtomofficial/Windows-System-Administration).
