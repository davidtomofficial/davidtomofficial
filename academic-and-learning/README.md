## Reading the evidence

The original repositories retain their source history, assignment identifiers, supporting files and existing notices. This index organizes links; it does not move the code or supply a new license for it. Course-provided tests, third-party images, library notices and file-specific grants remain attached to their original sources. Historical executables are not offered here as verified builds.

Some retained READMEs describe intended performance, memory behavior or compatibility. Treat those as historical claims unless a current source record provides a specific verification result. My current systems work remains in [Windows-System-Administration](https://github.com/davidtomofficial/Windows-System-Administration).
